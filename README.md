# Git Tutorial

```shell
# 깃 초기화
git init

# 스테이징 추가
git add .
git add -A
```

```bash
# 커밋
git commit -m "commit message..."
```

```bash
# 푸쉬 커멘드

git push origin main
```

```
```sh
# git 로그 명령어

git log

git log --oneline --all
```

### 브랜치 생성 및 스위치

```sh
git branch 브랜치명
git checkout 브랜치명

git checkout -b 브랜치명
```
